## API Reference
- [List boards.](https://roserocket.readme.io/reference/get_boards-nav.md)
- [List events for a given record.](https://roserocket.readme.io/reference/get_events.md)
- [Create an event.](https://roserocket.readme.io/reference/post_events.md)
- [List user groups](https://roserocket.readme.io/reference/listusergroups.md): Retrieves a list of all user groups belonging to the org.
- [Create user group](https://roserocket.readme.io/reference/createusergroup.md): Creates a new user group and returns the result.
- [List group members](https://roserocket.readme.io/reference/listusergroupmembers.md): Lists the users belonging to the indicated group.
- [Add or remove group members](https://roserocket.readme.io/reference/addusergroupmembers.md): Adds or removes users to/from the indicated user group.  **NOTE:** Removal takes prescendence over addition so if a user ID appears on both the `add` and `remove` collection, then that user will *NOT* be a member of the user group after the operation completes.
